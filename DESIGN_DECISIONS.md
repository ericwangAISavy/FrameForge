# Design decisions

WORLDSMITH is an engineering field journal, with the visual restraint of an independent studio art book. Charcoal and blue-gray establish depth; warm bronze marks decisions and interactive paths. Georgia supplies an editorial voice with no external font request. Sans-serif body text and monospaced metadata distinguish explanation from instrumentation.

The hero uses original layered SVG geometry: a distant gate, stone fragments, a winding path and a small human-scale marker. It stays light, readable and meaningful without WebGL. An inspect toggle exposes scene notes and the drawing grid. This is procedural portfolio illustration, not a fabricated gameplay image.

Work is presented as alternating editorial features. The quest diagram and memory archive vary the composition while sharing the grid and palette. Five technical notes make the reasoning explicit: problem, constraints, approach, architecture, trade-offs, edge cases, validation and lessons. Employer logos, inflated experience counters and skill ratings are absent.

Client JavaScript is limited to useful behaviors. Traversal is a deliberately discrete model with visible eligibility and recovery. Quest decisions have exclusive terminal states and validated session persistence. NPC behavior is a deterministic, inspectable state machine. The memory archive connects discovered evidence to two conclusions. Network resolution demonstrates authority and duplicate rejection using a stable event queue.

Desktop navigation is replaced by a labeled disclosure on small screens. Scene controls, quest actions and perception events work through native buttons. Traversal also accepts keyboard commands on its focusable scene. Reduced motion removes transitions and smooth scrolling. No hover-only essential content, scroll-reveal delays, tracking or autoplay media.

The source is fictional. This is a visually finished provisional portfolio, not a claim that an unidentified person shipped named commercial features. Labels, owner-editable content and launch checklists keep that boundary visible without filling the journal with false accomplishments. Identity and contact slots remain honest until supplied.
